# Grammar Exercise — Android APK Project

Generated by APKForge. Your HTML, CSS, JavaScript, and asset files are placed in:

```
app/src/main/assets/www/
```

## Option 1: Build APK in the Cloud (No Android Studio Required)

1. Create a new GitHub repository and push this folder to `main`.
2. Open the **Actions** tab in GitHub and run **Build Android APK** (or wait for the push workflow to finish).
3. Download the compiled **`app-debug.apk`** artifact and install it on any Android device.

## Option 2: Build Locally with Android Studio

1. Open this folder in **Android Studio**.
2. Wait for Gradle Sync to finish.
3. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Find your APK at `app/build/outputs/apk/debug/app-debug.apk`.

## Option 3: Build via Command Line (Gradle)

```bash
gradle assembleDebug
```
